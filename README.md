# 智研平台 · 产品介绍页

AI 深度研究与产业链招商决策引擎的前后台静态部署包。

## 页面模块

| 模块 | 说明 |
|---|---|
| 全国企业库 | 全国企业迁入迁出动态图，展示绿色迁入流线、红色迁出流线与净迁入指标。 |
| 数据与模型底座 | 全国企业主体数据、权威信源与四大模型引擎。 |
| 四大模型引擎 | 产业链构建及强弱分析模型、招商多因子评估模型、政策匹配引擎、企业尽调引擎。 |
| 典型应用场景 | 产业运行监测、企业流动洞察、招商线索雷达、企业尽调助手、政策匹配服务。 |
| 管理页 | `admin.html` 提供体验申请查看、筛选、备注、状态管理与导出界面。 |

## 本地预览

直接在浏览器打开 `index.html` 即可预览；建议使用本地 HTTP 服务获得与生产环境一致的资源加载行为：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 目录

```text
index.html          前台页面（内联 CSS / JavaScript）
admin.html          管理页面
images/             典型应用场景图片
nationwide-map.png  原始地图备份资源
DEPLOY.md           本地服务器部署说明
```

## 数据与登录说明

当前包为静态版本：留资数据保存在提交者浏览器的 `localStorage`，不会自动传到服务器，也不会被其他设备上的管理页读取。管理页的登录校验同样仅用于本地演示。

生产环境请在部署静态站点之外，单独配置 API、数据库和服务端会话认证。
