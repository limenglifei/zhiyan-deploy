## 关于留资表单

页面上的「申请体验」表单目前把数据写入浏览器 `localStorage`，**只存在提交者本机**，
不会回传到任何服务端。也就是说：**站点发布到公网后，访客提交的申请你收不到。**

要真正收集线索，需二选一：

1. 接入表单托管服务（Formspree / Tally / 飞书问卷等），把 `submitForm()` 改成 POST 到对应接口；
2. 自建后端接口 + 数据库，并在服务端做校验与存储。

在接入之前，建议把表单按钮文案改为引导邮件联系，或直接展示下方联系邮箱。
